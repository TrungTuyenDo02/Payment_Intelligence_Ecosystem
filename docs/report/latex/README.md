# Báo cáo thực tập (LaTeX)

Biên dịch bằng XeLaTeX (cần font TeX Gyre Heros và DejaVu Sans Mono, có sẵn trong TeX Live):

```bash
xelatex bao-cao-thuc-tap.tex && xelatex bao-cao-thuc-tap.tex
```

Chạy hai lần để có mục lục. Sau đó chép `bao-cao-thuc-tap.pdf` ra `docs/report/`. Hình trong `figures/` lấy từ `docs/assets/` (sơ đồ SVG xuất PNG gấp đôi độ phân giải). Trên Overleaf: chọn compiler XeLaTeX.

Mục 4.3 và 4.4 (Stage E) chờ số trên IEEE-CIS.
